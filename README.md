# Carto

Site de cartomancie traditionnelle (jeu de 32 cartes) : saisie d'un tirage d'ouverture, en ligne (7 cartes) ou en pyramide.

## Publier avec GitHub Pages
1. Déposer `index.html` à la racine du dépôt.
2. Settings > Pages > Source : branche `main`, dossier `/ (root)`.
3. Le site est disponible à l'adresse `https://pascalgir.github.io/Carto/`.

Note : le bouton « Interpréter le tirage » ne fonctionne que sur claude.ai.
